# 快速上手 · 不克隆仓库，5 分钟出第一张图

> 在线版地址：**https://gaoren7716-lab.github.io/anime-prompt-library/**
> 全部操作在浏览器里完成，不需要安装任何东西。

---

## 1. 先看效果（1 分钟）

打开在线版 → 左侧第一个「**示例画廊**」。

每张图下面就是生成它的完整提示词（GPT 正文），点「复制」即可。
先看 2–3 张，找到接近你想要的那种画面。

注意：示例画廊的图走 keyed 通道生成。**免 key 的 Sana 通道适合试构图与题材，
画风层在它那里基本不显形**（实测结论，详见 README「免 key 通道的实测边界」一节）——
想验证画风效果请用 keyed 模型。

## 2. 从零创作（2 分钟）

左侧第二个「**出图工作流**」，四步各选一条：

| 步骤 | 决定什么 | 怎么选 |
| --- | --- | --- |
| 画风 | 整幅怎么画（线条 / 上色 / 质感 / 光影） | 按「我想要这种效果」速查表，或在框里搜关键词 |
| 题材 | 画什么（主体 / 场景 / 叙事） | 按分类浏览或搜索 |
| 版式 | 怎么摆（构图 / 画幅 / 版面） | 社媒卡 / 信息图 / 海报各有预设 |
| 配色 | 什么颜色（主色 / 辅色 / 落色） | 每套配色都带具体色值 |

每一步都支持**中文名、别名、跨语言、描述式搜索**——比如直接搜「厚涂」「水彩」。

## 3. 拿到提示词（1 分钟）

工作流底部就是结果区：

- **默认提示词**：本库通用正文（基准版，中英双语）。
- **五个模型卡**：GPT-Image 2 / Nano Banana / Midjourney / Flux / Sana，
  每份都按该模型语法改写过，点卡片一键复制。
  Midjourney 卡是「标签串 + `--ar` 参数」，复制后到 midjourney.com/imagine 粘贴。

**每份结果都带效果说明**：四步各自决定什么、恒定保留什么（无文字 / 无水印的禁项
每版自带）、画风在你选的模型上叫不叫得动、哪些判断没经过实测。照着说明就知道
换模型会差多少。

## 4. 直接出图（1 分钟，可选）

不想离开页面的话：结果区切到「**Sana · 免 key**」模型点「立即出图」，
不要 API key 就能出图（约一半请求会被限流，自动重试）。
要 GPT-Image / Nano Banana / Flux 的画质，在输入框贴一个
[enter.pollinations.ai/keys](https://enter.pollinations.ai/keys) 免费申请的 key
（key 只存在内存里，刷新即消失，不会上传保存）。

还没想好选什么 → 左侧第三个「**一键抽卡**」，随机抽一组直接出。
